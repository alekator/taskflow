## Capture Guidance

- Use desktop-sized screenshots for the cleanest GitHub presentation.
- Keep browser chrome cropped unless it adds useful context.
- Prefer consistent width and aspect ratio across all images.
- Capture states with meaningful data already seeded.
- Avoid blank, loading, or unauthorized screens.
